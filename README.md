# Lakshya Saini - Premium Data Analyst Portfolio Website

Includes dashboard screenshots, projects, certifications, embedded resume, business problems solved, and contact links.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Create a GitHub repository named `portfolio-website`.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the full `assets` folder.
4. Go to Settings > Pages.
5. Source: Deploy from branch.
6. Branch: main, Folder: /root.
7. Save and wait 1-2 minutes.

Expected URL: https://lakshya-sainii.github.io/portfolio-website/
